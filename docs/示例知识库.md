# 数字人演示知识库（示例资料）

## 系统定位
本系统是部署在 Windows 电脑上的三维数字人演示终端，主要用于演示和场景介绍。
全屏黑底呈现一个三维人物，现实背景反射来自现场屏幕与环境，不是软件制造的物理透明。

## 技术组成
人物采用 Unity、ChatdollKit、UniVRM 和 uLipSync。本地服务采用 Python、FastAPI 和 SQLite。
人物在本机渲染，语音识别、对话和语音合成使用联网 AI 服务。显卡目标为 GTX 1660 Super。
这是原生 Windows 展示程序。Unity 引擎不是开源软件，ChatdollKit 等组件是开源项目。

## 使用方式
提供项目概览、业务流程、应用价值三个讲解主题。可开始、暂停、继续、上一章和下一章。
中途提问会暂停原讲解。追问结束后说“继续讲解”，从被打断的句子重新开始。
可以按键讲话。现场完成回声消除测试后，可在管理界面启用免按键对话。

## 可配置内容
可配置角色名称、身份、性格、回答长短、欢迎语、音色、语速、动作频率和绑定知识库。
预设角色为亲切接待、正式讲解和技术介绍。切换角色会清空当前对话。
人物形象通过导入带骨骼和口型的 VRM 资产替换。新发型或服装需要相应模型资产。
显示设置包括显示器、全屏、人物比例、位置、朝向、亮度、字幕和目标帧率。

## 知识与接口
资料支持 TXT、Markdown、DOCX 和有文字层的 PDF。扫描文件需要先转换为文字。
回答应根据资料，不知道的问题应明确说明。管理界面可以查看资料来源片段。
演示接口包括切换主题和查询状态。统计数据是固定的模拟数据，不是实时业务生产数据。
接口成功后才播报成功；接口失败、超时或主题不明确时不应假装完成。

## 网络与交付
断网仍能播放提前缓存的固定讲解；自由问答需要网络。当前版本不包含全离线大模型。
首版不包括声音克隆、定制职业女性模型和真实业务系统接入。
交付包括原生程序、本地服务、配置界面、示例资料、演示接口、启动入口和源码。
官方 AI 服务需要账号及调用额度。本示例没有报价、客户案例、投资回报或真实设备数量。
