# 小霖 4090 独立部署与启动

验证日期：2026-11-13。该部署用于同一有线局域网内体验 MuseTalk，不替换云端正式版。

## 访问和启动

- 当前电脑入口：http://127.0.0.1:18774/ 。页面通过 SSH 隧道访问 4090，音视频通过有线 WebRTC 直接传输。
- 以后双击项目根目录 `Open-Xiaolin-4090.cmd`：按需启动两个专用任务，建立隐藏 SSH 隧道并打开页面。
- 4090 必须开机，CMCC 用户保持登录；两个任务没有开机触发器。任务注册为 InteractiveToken，不能当作无人登录的系统服务使用。
- 首次访问允许麦克风；连接失败时点击“授权麦克风并连接”，随后点击“开启声音”。对话可输入文字，或点击“开启唤醒监听”后说“小霖小霖”。
- 页面为单会话体验，避免同时打开多个数字人页面争用会话。
- 只在 4090 本机使用时，可直接访问其 http://127.0.0.1:18774/，无需当前电脑的 SSH 隧道。

## 技术路线和目录

文字或浏览器麦克风 → 小霖 gateway → Qwen 实时语音 → PCM 音频 → MuseTalk 1.5 FP16 口型生成 → 1080×1920 人物素材合成 → WebRTC 音视频播放。

唤醒检测使用本机 CPU FunASR / SenseVoiceSmall；对话使用云端实时语音服务。仅 ASR 测试的 `cloud_calls=0`，不代表完整对话离线。

| 路径（4090） | 用途 |
|---|---|
| F:\xiaolin\venv | 独立 Python 3.12.7 环境 |
| F:\xiaolin\app\avatar-2d | 页面、gateway、人物素材、动作缓存 |
| F:\xiaolin\app\musetalk-eval\models | MuseTalk、VAE、Whisper、脸部分割模型 |
| F:\xiaolin\app\avatar-2d\models\SenseVoiceSmall | CPU 语音识别模型 |
| F:\xiaolin\state | 独立设置与 SQLite 状态 |
| F:\xiaolin\config\system.conf | 已授权复制的实时语音密钥，禁止打印或提交版本库 |
| F:\xiaolin\logs | 两个专用任务日志 |
| F:\xiaolin\start-xiaolin-4090.py | GPU 检查、资源限制、gateway 启动 |
| F:\xiaolin\xiaolin_lan_rtc.py | WebRTC 候选绑定到有线地址和专用 UDP 范围 |

主要依赖：torch 2.5.1+cu124、diffusers 0.32.2、transformers 4.48.3、aiortc 1.14.0、av 16.1.0、FunASR 1.3.1。独立环境 `pip check` 已通过。

## 服务、端口与资源策略

| 服务 | 入口 | Windows 任务名 |
|---|---|---|
| 页面 / gateway | 127.0.0.1:18774 | Xiaolin-MuseTalk-4090 |
| CPU ASR | 127.0.0.1:18780 | Xiaolin-ASR-4090 |
| WebRTC 媒体 | 10.36.154.54 UDP 10400–10449 | 随 gateway 运行 |

HTTP 不直接监听整个局域网。WebRTC 防火墙规则为 `Xiaolin WebRTC from 10.36.154.44`，只允许指定源 IP。当前使用有线 host candidate，没有为这一独立版本配置公网 TURN。

两个进程使用低于正常优先级。MuseTalk 启动前要求至少 7 GiB 空闲显存，PyTorch 分配器上限设为显存的 30%；这不是整个进程或整张显卡的硬配额，编码器、CUDA 上下文等仍会额外占用。关闭 cuDNN benchmark，MuseTalk 使用 2 个 CPU 计算线程，限制 OMP/MKL/OpenBLAS 线程。

本次最终快照整卡显存使用 7348 MiB、GPU 利用率 5%、系统可用内存 44.7 GiB。整卡数值包含其他程序，不能视为小霖单进程显存。

## 按需管理

在 4090 本机 PowerShell 执行：

```powershell
schtasks /Run /TN Xiaolin-ASR-4090
schtasks /Run /TN Xiaolin-MuseTalk-4090

# 只停止这两个小霖任务
schtasks /End /TN Xiaolin-MuseTalk-4090
schtasks /End /TN Xiaolin-ASR-4090

# 状态和日志尾部；不会输出密钥
F:\xiaolin\venv\Scripts\python.exe -X utf8 F:\xiaolin\status-xiaolin-4090.py
```

关闭页面会释放浏览器会话，但不会自动卸载后台模型。需要释放小霖常驻资源时结束上述专用任务。旧 `manage-xiaolin-4090.py` 的脱离 SSH 启动方式不作为启动入口，实际使用 Task Scheduler。

## 已验证结果和边界

- 服务器侧真实实时语音测试通过：收到视频 250 帧、音频 500 帧，其中 73 帧有声；1080×1920；打断后队列为 0，最终队列为 0，render_error=null。
- 当前电脑 Edge 连续收流约 13 分钟，累计解码 18312 帧；一次采样 24 fps，服务日志一般约 23 fps；该版本目标是 25 fps，不能宣称稳定 50 fps。
- 浏览器实际欢迎语测试触发 welcome-wave，记录 175 个动作帧，52 个口型推理帧。推理本身约 0.99 秒不代表端到端 50 fps。
- CPU ASR 对 1.6 秒既有唤醒样本识别为“小林啊小林。”，耗时约 0.99 秒。已验证浏览器麦克风数据送入 gateway，并在检查后停止监听。用户真实开口唤醒及主观听感仍需现场验收。
- 浏览器无麦克风权限时，此次只产生未连通候选；授权后出现有线候选并成功连接。独立页面新增授权连接按钮，重试保持 `iceTransportPolicy=all`，避免没有 TURN 时强制 relay。
- 当前仅对 Edge 做了实际收流检查，不能据此宣称 Firefox 已验收。
- 自动手势已开启；知识库、MCP、长期记忆关闭。其余动作素材和缓存已准备，但本轮未逐一完成有声动作的视觉验收。
- 此版使用裙子小霖原始 25 fps 素材及 MuseTalk；尚未迁移 T4 正式版全部 50 fps 调色、动作过渡和 C 嘴唇遮罩处理。
- 原云端正式环境没有在本次部署中切换。4090 上原有 LaMa 18841、LayerD 18847 仍监听；用户重启后 Image2PPT 8772、OpenCode 14100 未监听，本次没有代为恢复它们，端口监听也不等同完整业务验证。

本地证据在 `runtime/delivery4090/validation-local.json`、`validation-final.json`；远端同名文件在 F:\xiaolin。密钥、模型压缩包、运行缓存及用户状态不纳入提交。
