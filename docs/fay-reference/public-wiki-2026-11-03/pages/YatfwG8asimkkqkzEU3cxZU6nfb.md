# funasr热词接入

热词：是指在特定应用场景或领域中出现频率较高的重要词汇。

包括：

1.
高频词汇：在某个特定领域（例如医学、法律、游戏等）中，热词是那些经常被提及的词汇。它们在语音识别系统中被赋予更高的权重，以提高识别的准确率。

2.
定制词汇：用户可以根据自己的需求添加或调整热词。例如，一个游戏直播平台可能会将一些热门游戏的名称、游戏术语、以及主播昵称设定为热词，以确保这些词在直播中的识别率更高。

3.
上下文相关性：热词通常与当前语音识别的上下文密切相关。它们可以帮助系统更好地理解和处理特定场景下的语音输入。例如，在一次医学讲座中，“心脏病”、“手术”等词语可能被设定为热词。

使用热词的主要目的是增强语音识别系统的性能，使其在特定场景或领域中更加精确和可靠。这样可以确保特定情况下，重要的词汇能够被准确识别和理解，提高用户体验和系统的实用性。
