# fay接口

来源：https://qqk9ntwbcit.feishu.cn/wiki/Mcw3wbA3RiNZzwkexz6cnKCsnhh

我们认为一个开源数字人框架的重要责任之一是，给你提供一套可以把数字人融入自家产品的解决方案。所以我们Fay提供了一套适合接入各种垂直行业的代码和接口。你所要做的是，针对具体应用场景，选择合适的接口，配置合适的皮肤：

1、文字交互接口，支持多路输入输出，通过文字内容与数字人沟通；

2、语音交互接口，支持多路输入输出，websocket 的9001端口和tcp 10001端口其实是一样的，相当于远程麦克风和扬声器（可以不使用），在无法直接与fay沟通对话的时候使用；



3、数字人驱动接口，支持多路输出，通过输出声音、文字、情绪和唇形来驱动数字人;



4、控制接口，支持多路输入输出，把fay界面的所有功能都可以集成到你的产品;



5、播报接口，用于构建具备“自言自语”逻辑的数字人应用;



6、意图接口，用于向fay传达明确的意图：唤醒、打招呼、打断说话。
